# 실제 사이트 전용 Dino AI v0.4.0

학습 장소: https://chrome-dino.org/ko/classic/

이 확장은 실제 Chrome Dino 사이트의 캔버스를 읽고 ↑ 점프, ↓ 숙이기, Enter 재시작으로 Q-learning을 수행합니다. 별도 로컬 시뮬레이터나 사전 학습 모델은 사용하지 않습니다.

## v0.4.0 핵심 변경점

- 처음 보는 상태에서 Q값이 모두 같을 때 무조건 run을 고르던 편향을 제거했습니다.
- 새 상태에는 장애물 종류와 거리에 맞는 작은 초기 Q값을 넣어, 시작부터 선인장에 계속 박는 현상을 줄였습니다.
- 탐험 비율 기본값을 0.30으로 올리고, 게임오버마다 자동으로 감소해 최소 0.05까지 내려갑니다.
- 상태 공간을 6개 축에서 4개 축으로 단순화해 비슷한 상황의 경험을 더 빨리 재사용합니다.
- 의사결정 주기를 약 50ms로 낮춰 같은 프레임을 과도하게 학습하던 문제를 줄였습니다.
- 장애물 통과 보상을 크게 올리고, 너무 멀리서 점프하거나 숙이는 행동에는 작은 벌점을 줍니다.
- 충돌 직전 약 0.7초의 행동 기록에도 감쇠된 패널티를 되돌려 주어, 너무 늦게 반응한 행동을 더 빨리 학습합니다.
- 공중에서는 다시 점프하지 않도록 행동 후보를 제한하고, 장애물이 너무 멀면 불필요한 랜덤 행동을 하지 않습니다.
- 프레임 수로 추정하던 속도 대신 장애물의 실제 픽셀 이동량으로 속도를 추정합니다.
- AI 최고점과 사이트 최고점을 분리했습니다. 사이트 최고점에는 사용자가 직접 플레이한 기록도 포함될 수 있습니다.
- v0.3 정책과 섞이지 않도록 저장 키와 상태 스키마를 새 버전으로 올렸습니다. 따라서 v0.4 학습 횟수와 Q 상태는 새로 시작합니다.
- 팝업과 게임 내 위젯에 **업데이트 확인** 기능을 추가했습니다.

## 설치 / 갱신

처음 설치:

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 누릅니다.
4. `dino-site-ai/extension` 폴더를 선택합니다.
5. https://chrome-dino.org/ko/classic/ 를 새로고침합니다.

GitHub에서 새 버전이 올라온 뒤 갱신:

```powershell
cd "C:\Users\gimye\Documents\Codex\2026-10-06\ARGUS"
git pull origin main
```

그다음 `chrome://extensions`에서 Dino AI 확장의 **새로고침 버튼**을 누르고 게임 페이지도 새로고침합니다.

> 압축해제된 개발자용 Chrome 확장은 보안상 스스로 파일을 덮어써서 완전 자동 업데이트할 수 없습니다. 현재의 업데이트 버튼은 GitHub의 최신 버전을 확인해 새 버전 존재 여부를 알려주는 방식입니다.

## 학습 방법

처음에는 탐험 비율 0.30으로 시작하는 것을 권장합니다. v0.4에서는 학습 중 게임오버가 발생할 때마다 탐험 비율이 자동으로 감소하며 0.05 아래로는 내려가지 않습니다.

- **학습**: Q값을 계속 갱신하며 죽으면 자동 재시작합니다.
- **실행**: 학습 없이 현재 정책만 사용합니다.
- **중지**: 자동 입력과 예약된 재시작을 모두 중단합니다.
- 다른 탭으로 이동하면 안전을 위해 자동으로 중지합니다.

화면의 기록은 다음 의미입니다.

- 현재 점수: 현재 AI 플레이의 실제 화면 점수
- AI 최고점: v0.4 AI가 실제로 기록한 최고 점수
- 사이트 최고점: 사이트 로컬 저장소의 전체 최고 기록. 사람의 기록이 포함될 수 있음
- 실제 학습 횟수: v0.4에서 게임오버까지 학습한 판 수
- Q 상태 수: 현재 정책에 만들어진 상태 수

## 검증

프로젝트 폴더에서:

```powershell
node verify.cjs
```

정적 검증은 Q-learning, 상태 스키마, 게임오버 픽셀 감지, 사이트 전용 content script, v0.4 설정과 업데이트 확인 코드를 검사합니다.

실제 사이트 장시간 플레이 결과는 사용 환경에서 별도로 확인해야 합니다. 특히 2,000점 달성은 아직 보장된 값이 아닙니다.
