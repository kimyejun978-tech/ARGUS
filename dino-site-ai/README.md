# 실제 사이트 전용 Dino AI v0.3.0

학습 장소: https://chrome-dino.org/ko/classic/

이 확장은 실제 게임의 캔버스를 관찰하고 ↑ 점프, ↓ 숙이기, Enter 재시작으로 학습합니다. 로컬 게임과 사전 학습 모델은 포함하지 않습니다. 기존 로컬 학습 횟수도 가져오지 않습니다.

## 설치

1. Chrome의 확장 프로그램 관리 화면을 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
3. 이 폴더 안의 `extension` 폴더를 선택합니다. ZIP을 받았다면 먼저 압축을 풉니다.
4. 실제 사이트를 새로고침하고 오른쪽 아래 **학습** 버튼을 누릅니다.

확장의 실행 권한은 해당 사이트의 한국어 클래식 페이지로 제한됩니다. 정책은 컴퓨터의 Chrome 저장소에 저장됩니다. 별도 서버는 필요하지 않습니다.

## 기록의 의미

- 현재 점수: 게임 캔버스에 실제로 표시된 숫자입니다. 읽을 수 없거나 순간적으로 비정상적인 값이 나오면 직전 값을 유지하며 시간을 점수로 환산하지 않습니다.
- 사이트 최고점: 사이트에서 저장한 실제 최고 기록입니다.
- 학습 판수: 이 버전이 실제 사이트에서 학습하며 끝낸 게임 수입니다. 프레임 수나 로컬 시뮬레이션 횟수가 아닙니다.
- 실행: 탐험 없이 저장된 정책으로 플레이합니다. 실행 중에는 정책을 학습하지 않습니다.
- 중지: 자동 입력을 해제합니다. 다른 탭으로 이동해도 중지합니다.

처음에는 정책이 비어 있어 성적이 낮을 수 있습니다. 학습 횟수가 늘었다는 사실만으로 실력이 좋아졌다고 판단하지 마세요. 실제 점수와 학습 종료 후 실행 성적을 확인해야 합니다. 2,000점 달성은 아직 검증하지 않았습니다.

## v0.3.0에서 고친 점

- 실제 사이트 엔진은 게임오버 때 내부 상태는 바꾸지만 `.runner-container.crashed` 클래스를 안정적으로 추가하지 않습니다. 그래서 클래스만 보던 이전 감지는 게임오버를 놓칠 수 있었습니다. 이제 캔버스 중앙의 `GAME OVER` 영역을 픽셀로 감지합니다.
- 게임오버 뒤 재시작 예약이 남아 있어도 **중지**를 누르면 추가 키 입력이 나가지 않도록 모든 재시작 경로에서 `running`을 다시 확인합니다.
- 점수 OCR이 한 프레임에서 크게 튀거나 감소하면 버리고, 정상적인 증가만 학습 보상과 최고점에 반영합니다. 100점 단위 깜빡임 때 숫자를 못 읽으면 직전 점수를 유지합니다.
- 정책 가져오기 시 존재하지 않던 `applyPolicyMetadata()` 호출 문제를 수정했습니다. 래퍼 형식의 정책과 직접 정책 모두 메타데이터를 읽습니다.
- 캔버스가 아직 준비되지 않은 상태에서는 Q-learning과 자동 입력을 시작하지 않습니다. 우측 위젯/팝업에서 **캔버스 감지**, **점수 판독** 상태를 확인할 수 있습니다.
- 이전 오류 상태의 자동 저장 정책과 섞이지 않도록 실제 사이트 자동 저장 키를 `v2`로 올렸습니다. 수동으로 내보낸 정상 정책은 가져오기 기능으로 다시 넣을 수 있습니다.

## 자동 적용의 한계

현재 브라우저 제어 도구는 `chrome://` 내부 페이지 접근을 허용하지 않아 확장 설치를 대신 완료할 수 없습니다. 따라서 설치와 실제 사이트에서의 실행 검증은 아직 완료되지 않았습니다.
