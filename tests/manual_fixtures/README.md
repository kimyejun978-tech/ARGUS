# ARGUS realistic public-portal fixture

`realistic_public_portal.html` is a standalone, safe synthetic test page.

It intentionally looks like an ordinary public-service portal while embedding
test-only examples for ARGUS:

- transparent text
- opacity-hidden text
- off-screen text
- Hangul Jamo obfuscation
- digit-based homoglyph text
- a harmless automatic `.txt` download attempt for auxiliary diagnostics

The file contains no real illegal-service links, credentials, executables, or
restricted-service instructions.

For manual GUI testing, choose this file with **파일 선택** and start the scan.
